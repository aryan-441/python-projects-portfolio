# Snake Game

A Turtle-based Snake game with keyboard controls, food collection, body growth, collision detection, and a saved high score.

## Controls and implementation

Use **W**, **A**, **S**, and **D** to steer. The source separates the snake, food, and scoreboard into Python files and updates the screen in a timed loop.

## Requirements and setup

Python 3 with Tkinter/Turtle. Run `python main.py` from the `snake_game` folder; the high-score file is relative to the working directory.
