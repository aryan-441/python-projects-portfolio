# Python Course Projects

A curated set of Python exercises and applications completed while following course material. The collection keeps course-derived work together and gives each selected project its own folder and README. Course attribution and original authorship should be stated accurately; this repository should contain only files that can be redistributed.

## Included projects

- [Flash Cards](flash-cards/README.md): Spanish/English vocabulary cards with known-word tracking.
- [Blackjack](blackjack/README.md): a console card game with card, deck, hand, and chip classes.
- [Snake](snake/README.md): a Turtle game with separate game components and saved high score.
- [Pong](pong/README.md): a two-player Turtle game.
- [Turtle Crossing](turtle-crossing/README.md): a Turtle road-crossing game.
- [Guess the State](guess-the-state/README.md): an interactive map quiz.

## Requirements

Projects have different requirements. Most use Python's standard library and Tkinter/Turtle; Flash Cards and Guess the State also use pandas. See each project README. Dependency versions have not been pinned because the source does not provide a verified manifest.

## Dates and attribution

The individual source files do not state authored project dates. The dates recorded in the proposal are Drive file metadata and should not be described as confirmed creation/release dates. Course-derived projects must remain clearly labelled as such.
