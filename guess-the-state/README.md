# Guess the State

An interactive United States map quiz built with Turtle and pandas. Players type state names and the program marks recognized answers on the map while tracking progress.

## Requirements and setup

Python 3, pandas, the map image, and the state CSV. Run from the project folder so relative asset paths resolve. Install pandas with `python -m pip install pandas` if needed.
