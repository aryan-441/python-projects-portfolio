# Turtle Crossing

A Turtle game in which the player moves upward across a road while traffic moves across the screen. The code separates player, car management, and scoreboard logic.

## Controls

Press **W** to move upward.

## Requirements and setup

Python 3 with Tkinter/Turtle. Run `python main.py` from the `turtle_crossing` folder.

## Limitations and attribution

This is course-derived work. The current implementation ends the game after a collision and advances levels when the player reaches the far side; controls and restart behavior are limited. Drive metadata for `main.py` is 2026-05-06 created and 2026-05-07 modified.
